# Portfolio

Projeto com React, TypeScript, Vite e Tailwind CSS.

## Desenvolvimento

```sh
npm.cmd install
npm.cmd run dev
```

Abra o endereço local exibido pelo Vite. Edite `src/App.tsx` para alterar a tela e use as classes do Tailwind diretamente no JSX.

## Verificação e produção

```sh
npm.cmd run lint
npm.cmd run build
npm.cmd run preview
```

A compilação de produção fica em `dist/`.

No PowerShell, use `npm.cmd` caso a política de execução bloqueie `npm.ps1`.
